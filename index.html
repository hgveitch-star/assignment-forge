The Assignment Forge

You've probably tried using AI for an essay. That's not this.

This tool doesn't write your essay. You do. What it does is help you think like a member of your discipline — to read carefully, argue clearly, and know why you're saying what you're saying.

The world you're graduating into has AI in it. Everywhere. The question is no longer whether you'll use it. It's whether you'll still know how to think when it's at your elbow.

We're not here to help you pass. We're here to help you learn how to work in a world where AI is everywhere, and you're still the one whose name goes on the work.

Before we start, the rule.

The rule is simple, and it doesn't move: you write it. The tool helps you think. It does not produce the prose. When you ask it to write your essay, it will say no — kindly, but firmly.

Why it matters — three reasons.

  1. It's how thinking develops. An argument you build yourself becomes yours. An argument you copy becomes someone else's, and you carry it like borrowed clothing.
  2. Your institution's rules apply. Whatever your university says about AI use in assignments, that's the rule. This tool works within it.
  3. You should be able to defend every word. If a lecturer asked you "why did you say this?", you should have an answer that's yours.

Connect an AI provider.

This tool runs in your browser. No account, no server, no data collection. To use the AI features, you bring your own API key from one of the providers below. You pay them directly — usually a few US cents per assignment.

Your key stays on your device. It never passes through any server of ours, because there isn't one.

Choose a provider above, then paste the key it gave you.
Model names change. If a call fails, check your provider's current model list.
Never set up an API key before? 2-minute guide.

An API key is a long string of letters and numbers that lets a piece of software talk to an AI provider on your behalf.

1. Go to the provider's website and sign up.

2. Find the "API keys" section in your settings.

3. Click "Create new key". Copy the key now.

4. Add a small amount of credit. A few dollars lasts months.

5. Paste it here. That's it.
